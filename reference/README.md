# Original project scripts

These scripts are unmodified copies from the recovered project backup; SHA-256 checksums are in `PROVENANCE.json`.
They document the historical production and expert workflows, including original training and fine-tuning code.
They contain server-specific paths and top-level setup/training side effects. Do not import them as library modules.

Use `run_pipeline.py` or the notebook for portable inference. That implementation is adapted and versioned;
it does not claim a byte-for-byte replay of the original thesis analysis. Differences are documented in
`docs/IMPLEMENTATION_NOTES.md`. Historical datasets, slide mappings and annotation manifests are not published here.
